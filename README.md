# mitmal_latex

Reusable MIT-MAL LaTeX starter files.

## Included files
- `main.tex` — initial blank document
- `llncs.cls`
- `mitmalstyle.sty`
- `mitmalpackages.sty`
- `mitmalfigures.sty`
- `mitcolor.sty`

## Build
```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

If you add a bibliography, run BibTeX as usual.
